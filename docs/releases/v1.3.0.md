拾忆 1.3.0：AI 模型设置改为「选服务商 + 填 Key」。

已装 1.2.x：设置 → 关于 → 检查更新 → 立即更新。

## 新功能

- **主流模型服务商一键配置**：设置 → AI 模型 里列出 12 家服务商——
  - 国内：DeepSeek、阿里云百炼、月之暗面 Kimi、智谱 GLM、火山方舟豆包、硅基流动
  - 海外：Anthropic、OpenAI、Google Gemini、OpenRouter
  - 本地与自定义：Ollama、自定义（LiteLLM、自建网关）
  
  选中一家，接口地址和格式自动填好，点「去获取」直达它的 Key 页面，粘贴 Key 即可。
- **从服务商拉取模型列表**：点「获取模型列表」，主模型和快速模型直接从下拉里选，也可以手动填写。
- **每家的 Key 分开保存**：在服务商之间切换不会丢配置；界面上只显示 Key 的首尾几位。
- **测试连接**针对当前查看的服务商，显示耗时和回复，不会改动正在使用的服务商。

## 升级说明

原来填的接口会自动归到对应的服务商卡片下（比如 DeepSeek），地址、格式、模型和 Key 都保持不变，不用重新填。
