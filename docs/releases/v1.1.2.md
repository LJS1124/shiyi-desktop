拾忆 1.1.2：AI 回复更稳，AI 补全的任务会自动排日期。

## 下载

- **Shiyi_1.1.2_universal.dmg**（macOS）：打开后把 Shiyi 拖进「应用程序」，选「替换」。同时支持 Apple 芯片和 Intel，需要 macOS 11 或更新。
- Shiyi.app.zip：同一个应用的压缩包。
- **Shiyi_1.1.2_x64-setup.exe**（Windows）：64 位，Windows 10 或更新，直接覆盖安装。没有代码签名，SmartScreen 提示时点「更多信息」→「仍要运行」。

更新不会动你的数据：数据和应用分开存放，新版第一次打开时还会先完整备份一份数据库。macOS 第一次打开前仍需在「终端」里执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/Shiyi.app
```

## 改进

- **AI 补全任务会排日期**：AI 会标出每条新任务要等哪些任务先完成，添加时自动连上依赖，并按前置和工期排出开始、截止日期；已有日期的任务不动。
- **AI 输出额度提高**：默认 16000 token，还不够时自动加到 32000；接口不接受这么大的额度时自动降下来。带思考过程的模型（如 DeepSeek）不再因为额度不够而只回一半。
- **回复被截断时保留完整的部分**：万一回复仍被截断，其中完整的条目照常显示、可以添加，并提示回复不完整。
