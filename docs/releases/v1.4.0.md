拾忆 1.4.0：⌘K 搜索与命令、每天的提醒、Windows 托盘，以及在应用里直接反馈问题。

已装 1.2.x 或 1.3.x：设置 → 关于 → 检查更新 → 立即更新。

## 新功能

- **⌘K 搜索与命令**（Windows 上是 Ctrl+K），在任何界面都能用：
  - 一个框里搜灵感、任务、项目、思维导图（包括每个节点）和标签，回车直接打开；导图节点会在导图里选中并居中。
  - 标题命中的排在前面，未完成的排在已完成前面；只有备注命中时，会显示命中的那一段。
  - 不输入时显示最近打开过的内容和常用命令。
  - 也能直接执行命令：打开某个视图、新建项目或导图、切换深浅色、打开设置、检查更新、AI 排今日、导出备份等。
  - 搜不到时，回车就把这句话记成灵感（也可以选「记成任务」）。
  - 顶栏右上角多了一个搜索按钮。
- **每天的今日摘要**：每天到点（默认 9:00）发一条系统通知，比如「今天要做 4 件，逾期 1 件：交物业费、写打分脚本……」。
  - 今天没有到期或逾期的任务时不打扰。
  - 错过了时间（比如 10 点才开电脑）会在打开时补发；晚上 9 点以后不再补发。
  - 在 设置 → 提醒与后台 里可以关闭、改时间，或点「发一条试试」。
- **Windows：关闭窗口缩到托盘**：关掉窗口后拾忆留在任务栏右下角，提醒和全局快捷键照常工作。
  - 点托盘图标打开；右键菜单有「快速记录」和「退出拾忆」。
  - 不想要的话，在 设置 → 提醒与后台 里取消勾选，关闭窗口就是退出。
  - 再次从开始菜单打开拾忆时，会回到已经在运行的那个窗口，不会开第二个。
- **开机自动启动**（macOS 和 Windows）：在 设置 → 提醒与后台 里打开，开机后在后台等着提醒你，不弹出窗口。默认关闭。
- **诊断信息与反馈问题**：设置 → 关于 里新增两个按钮（⌘K 里也能找到）。
  - 「诊断信息」列出版本、系统、数据条数、最近的报错和后台日志，不含任何笔记内容和 API Key，可以一键复制。
  - 「反馈问题」会在浏览器里打开拾忆在 GitHub 上的新建 Issue 页面，把你写的描述和诊断信息填好，登录 GitHub 后点提交即可。

## 改动

- **快捷键调整**：⌘K 改为搜索与命令；聚焦顶部记录框改为 ⌘N（Windows 上是 Ctrl+N），`/` 照旧可用。
- 后台日志记在数据文件夹的 `logs/shiyi.log`，只记启动、备份、AI 和更新请求失败的原因，不记笔记内容、提示词和 Key。

## 升级说明

数据不受影响。更新后第一次打开会照常先完整备份一份数据库。Windows 上更新后第一次关闭窗口时，会弹一条通知说明拾忆去了托盘。
