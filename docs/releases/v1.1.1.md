拾忆 1.1.1：修复内置 AI 在部分模型上报「接口返回里没有文本内容」。

## 下载

- **Shiyi_1.1.1_universal.dmg**（macOS）：打开后把 Shiyi 拖进「应用程序」。同时支持 Apple 芯片和 Intel，需要 macOS 11 或更新。
- Shiyi.app.zip：同一个应用的压缩包。
- **Shiyi_1.1.1_x64-setup.exe**（Windows）：64 位，Windows 10 或更新。没有代码签名，SmartScreen 提示时点「更多信息」→「仍要运行」。

从 1.1.0 升级直接覆盖安装，数据不受影响。macOS 第一次打开前仍需在「终端」里执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/Shiyi.app
```

## 新功能

- **新版本提醒**：有新版本时侧栏底部会提示，点开能看更新说明、一键下载安装包。设置 → 关于 里可以手动检查或关掉自动检查。只访问 GitHub，每天最多两次。
- **升级前自动备份**：新版本第一次打开时，先把整个数据库完整备份一份（保留最近 5 次）。数据本来就和应用分开存放，覆盖安装不会动它。
- **GitHub 链接**：侧栏底部和 设置 → 关于 里都能直接打开项目主页。

## 修复

- **内置 AI 读不到回复**：带思考过程的模型（如 DeepSeek 的 Anthropic 兼容接口）在「补全任务」「估算工期」这类输出较长的功能上，会把输出额度花在思考上而没有正文。输出额度从 4096 提高到 16000，还不够时自动加到 32000；接口不接受这么大的额度时自动降下来。仍被截断的回复会保留其中完整的条目。
- **兼容更多网关的回复格式**：分段的正文、流式返回、与设置里选的格式不一致的回复，都能正确读取。
- **报错更具体**：仍然读不到时，会说明是额度用完、被内容过滤，还是附上接口实际返回的内容。
