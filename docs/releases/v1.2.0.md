拾忆 1.2.0：应用内一键自动更新。

## 下载

- **Shiyi_1.2.0_universal.dmg**（macOS）：打开后把 Shiyi 拖进「应用程序」，选「替换」。同时支持 Apple 芯片和 Intel，需要 macOS 11 或更新。
- Shiyi.app.zip：同一个应用的压缩包。
- **Shiyi_1.2.0_x64-setup.exe**（Windows）：64 位，Windows 10 或更新，直接覆盖安装。没有代码签名，SmartScreen 提示时点「更多信息」→「仍要运行」。

**这是最后一次需要手动安装。**从 1.2.0 开始，有新版本时点「立即更新」即可，拾忆会自己下载、核对签名、安装并重启。

更新不会动你的数据：数据和应用分开存放，新版第一次打开时还会先完整备份一份数据库。macOS 第一次打开 1.2.0 前仍需在「终端」里执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/Shiyi.app
```

## 新功能

- **一键自动更新**：侧栏出现「新版本可以更新」时，点开后选「立即更新」，带下载进度；更新包有签名，只会安装官方发布的版本。自动更新失败时仍可以下载安装包手动更新。
