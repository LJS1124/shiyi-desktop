拾忆 1.1.0：你和 AI 助手共用一份数据。

## 下载

- **Shiyi_1.1.0_universal.dmg**（macOS）：打开后把 Shiyi 拖进「应用程序」。同时支持 Apple 芯片和 Intel，需要 macOS 11 或更新的版本。
- Shiyi.app.zip：同一个应用的压缩包，不想用 dmg 时可以下载这个。
- **Shiyi_1.1.0_x64-setup.exe**（Windows）：64 位，Windows 10 或更新。装在当前用户下，不需要管理员权限。没有代码签名，SmartScreen 提示时点「更多信息」→「仍要运行」。

macOS 应用没有付费的 Apple 开发者签名，第一次打开前要在「终端」里执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/Shiyi.app
```

## 新功能

- **新增 Windows 版**：窗口用系统自带的标题栏，全局唤出记录框改为 Ctrl+Alt+Space，命令行装成 `shiyi.cmd`，其余功能和 macOS 一样。
- **改名「拾忆」**：图标不变；数据、命令行都不受影响。
- **数据改存 SQLite**：每次修改都留有修改前后的快照，可以撤销；每天自动备份。第一次打开时会自动导入旧版的 `data.json`。
- **AI 助手接入**：设置 → AI 接入，可以一键安装 `shiyi` 命令行和 Claude Code 技能，Claude Code、Codex 等就能读写你的灵感、项目和任务。权限分只读、可写、完全三档；可写权限下，AI 建的关联必须由你确认。
- **知识图谱**：手动关联、AI 建议、`[[双链]]`、标签、项目归属和依赖都画在一张图上，可以只看某一条周围的局部，也可以拖线建关联。
- **可能相关**：记下灵感时，提示和它相关的已有条目。只比较文字，不调用 AI。
- **AI 找关联**：只在你点按钮时运行，先选范围，会显示大约用多少 token。
- **操作记录**：你和 AI 的每次修改都按批次记下。连续修改会自动归成一组，可以筛选、搜索、撤销。
- **思维导图**：编辑节点时，输入框就地贴合节点；修改记录会写清楚加了、删了、改了哪个节点。

完整介绍见 [README](https://github.com/LJS1124/shiyi-desktop#readme)。
