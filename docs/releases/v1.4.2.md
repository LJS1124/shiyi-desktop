已装 1.2.x 及以上：设置 → 关于 → 检查更新 → 立即更新。

## 今日页

- **之前计划、还没做完**：放进「今日」但当天没做完的任务，以前第二天会从今日里消失；现在会出现在今日页最上面。可以点 ☀ 逐条放进今天，也可以「全部放进今天」或「不再提醒」。每天早上的摘要通知也会带上它们。
- **接下来 7 天**：今天的任务下面，按「明天、周五……」列出这几天要到期的任务，可以折叠。
- **逾期一键改期**：逾期任务右侧有「今天 / 明天 / 下周一」，点一下就改好，有开始日期的会整段顺移。

## 找得回

- **从备份恢复**：设置 → 数据 → 从备份恢复…，列出每份自动备份的时间和里面的条数，选一份就恢复。恢复前会先把现在的数据另存一份，恢复后点「撤销恢复」或在列表里选那份就能换回来。
- **最近删除**：操作记录 → 最近删除，删掉的灵感、项目、任务和导图一键恢复；删项目时一起删掉的任务会跟着回来。
- **⌘Z 撤销、⇧⌘Z 重做**（Windows 上是 Ctrl+Z、Ctrl+Shift+Z）：在任何视图里撤销自己刚才的修改。输入框里照旧是撤销文字，AI 的修改不会被 ⌘Z 撤掉。

## 显示

- 已完成的任务不再显示「逾期 N 天」，改为「完成于 10/22」。
- 日历按窗口高度放下整个月，打开时能看到本周；格子放不下的任务显示「+N」。
- 灵感页改成一行一条，宽屏不再右边大片空着；窗口窄时操作按钮只显示图标。
- 甘特图里从左边以外开始的任务条，标题贴着可见区域显示，不再被切掉一半。
- 小窗口：侧栏底部精简（导出、导入在设置里，快捷键点「快捷键」查看）；网络图、知识图谱打开时不会缩得太小看不清；思维导图放得下就整张显示，放不下就以中心主题居中。
- 窗口大小和位置会记住，下次打开还是上次的样子；上次的位置在已经拔掉的显示器上时，会回到主屏幕。

- `shiyi today` 多了 `carried_over`：之前计划、还没做完的任务。技能说明已更新，AI 会先问你要不要放进今天。
