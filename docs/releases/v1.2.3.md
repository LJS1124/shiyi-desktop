拾忆 1.2.3：检查更新更可靠。

## 修复

- **检查更新报 HTTP 403**：以前检查更新走 GitHub 的接口，它对同一个出口 IP 每小时只允许 60 次，用代理、公司或校园网络时容易被别人用完额度。现在改为读取每个版本附带的更新清单（和自动更新用的是同一份），不受这个限制；读不到时才退回原来的接口，失败时会说明具体原因。

## 怎么升到这个版本

- 已装 1.2.x：设置 → 关于 → 检查更新，出现「立即更新」就点它。如果仍然提示 403，过一小时再试，或者在 [Releases](https://github.com/LJS1124/shiyi-desktop/releases/latest) 手动下载安装一次；装上 1.2.3 之后就不会再遇到这个问题。
